# RMT-3012: The server could not be reached

Shown by: the Remotely app and the Server Manager.

## What it means

A connection to the server's address could not be opened: wrong address, no internet, the server is off, or a firewall or router blocks the port.

## What to do

Run the Network test. Check the address, that the server is running, and that its port is open in the server PC's firewall and forwarded in the router.
