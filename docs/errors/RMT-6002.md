# RMT-6002: That public name cannot be used

Shown by: the Remotely Server Manager.

## What it means

The optional public name or address has a scheme (https://), spaces, a bad port, or an IPv6 address without square brackets.

## What to do

Type only a name such as myhome.example.com or an IP address, optionally with :port. You can leave it empty.
