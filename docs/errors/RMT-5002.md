# RMT-5002: The file is too large

Shown by: the Remotely app.

## What it means

The file or folder is larger than the limit set on the receiving side (a file may be up to 512 MB by default; a folder has a limit on its size and on its number of files).

## What to do

Split it or compress it, then send the parts.
