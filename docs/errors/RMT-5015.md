# RMT-5015: The transfer failed

Shown by: the Remotely app.

## What it means

Windows or the other PC reported a problem that has no code of its own. The message next to the code has the details.

## What to do

Read that message and try again. If it repeats, export diagnostics.

See also: [troubleshooting](../troubleshooting.md), [all error codes](README.md).
