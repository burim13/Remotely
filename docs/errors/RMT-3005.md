# RMT-3005: The server answered in an unexpected way

Shown by: the Remotely app.

## What it means

The reply was not what this app expects, or the server closed the connection. The address may belong to another service, or a proxy or filter changed the traffic.

## What to do

Check the server address. Run the Network test. Restart the server from the Server Manager if it is yours.

See also: [troubleshooting](../troubleshooting.md), [all error codes](README.md).
