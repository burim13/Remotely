# RMT-3006: The server refused the pairing code

Shown by: the Remotely app.

## What it means

The code is wrong, was already used, or has expired (codes last 15 minutes by default).

## What to do

Make a new invite or pairing code on the server and use that one.

See also: [troubleshooting](../troubleshooting.md), [all error codes](README.md).
