# RMT-1006: No PC answered the search

Shown by: the Remotely app and the Server Manager.

## What it means

Nobody on this network answered the search for the token. The other PC may not be sharing, may use another network, or the network may block broadcasts (guest Wi-Fi often does).

## What to do

Check that the other PC shows a token and that both PCs are on the same Wi-Fi or router. Allow Remotely in Windows Firewall on both PCs. If it still fails, type the other PC's address next to the token.
