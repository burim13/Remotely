# RMT-1003: The address is not valid

Shown by: the Remotely app.

## What it means

The address box does not hold an IPv4 address such as 192.168.1.20, optionally followed by :port.

## What to do

Check for typing mistakes. Leave the box empty to let Remotely find the PC from the token.
