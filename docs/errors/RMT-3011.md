# RMT-3011: That device cannot be connected to

Shown by: the Remotely app.

## What it means

The server does not know the device, you chose this very PC, or that device does not accept connections.

## What to do

Choose another device from the list. A device that only controls others cannot be connected to.

See also: [troubleshooting](../troubleshooting.md), [all error codes](README.md).
