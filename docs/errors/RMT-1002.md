# RMT-1002: That is an IPv6 address

Shown by: the Remotely app.

## What it means

Same-network connections use IPv4 addresses (like 192.168.1.20). An IPv6 address was typed.

## What to do

Type the IPv4 address shown on the other PC. If that PC has no IPv4 address, use a network that hands out IPv4 addresses.
