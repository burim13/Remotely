# RMT-2001: The other side did not speak Remotely correctly

Shown by: the Remotely app.

## What it means

The program that answered sent data that is not a valid Remotely handshake: another program uses the port, or the versions are too different.

## What to do

Check that the other PC runs Remotely and update both PCs to the same version.
