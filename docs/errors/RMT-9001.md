# RMT-9001: Something unexpected went wrong

Shown by: the Remotely app and the Server Manager.

## What it means

The program hit a problem that has no code of its own.

## What to do

Try again. If it repeats, open Help, Diagnostics, export diagnostics and report it with the details shown.

See also: [troubleshooting](../troubleshooting.md), [all error codes](README.md).
