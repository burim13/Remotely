# RMT-1005: This PC has only an IPv6 address

Shown by: the Remotely app and the Server Manager.

## What it means

Same-network connections need IPv4, and this PC only has IPv6 addresses.

## What to do

Use a network that gives out IPv4 addresses, or turn IPv4 on for this network connection in Windows.
