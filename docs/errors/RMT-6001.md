# RMT-6001: The invite is not valid

Shown by: the Remotely app.

## What it means

The text is not a complete Remotely invite: it does not start with RMT1-, is cut short, has a typing mistake, or was made by a newer Remotely.

## What to do

Copy the whole invite again from "Remotely Server info" on your server (one long line). Update Remotely if the invite is from a newer version.

See also: [troubleshooting](../troubleshooting.md), [all error codes](README.md).
