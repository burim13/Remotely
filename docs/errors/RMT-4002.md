# RMT-4002: The server's admin port cannot be reached

Shown by: the Remotely Server Manager.

## What it means

The admin port is open on this PC only while the server runs.

## What to do

Start the server on the Service page, then try again. Run the Manager on the same PC as the server.

See also: [troubleshooting](../troubleshooting.md), [all error codes](README.md).
