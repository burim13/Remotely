# RMT-1008: The other PC did not accept the token

Shown by: the Remotely app.

## What it means

The token was already used, has expired (a token lasts 10 minutes), or was mistyped.

## What to do

Read the token the other PC shows now and type that one.

See also: [troubleshooting](../troubleshooting.md), [all error codes](README.md).
