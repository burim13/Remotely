# RMT-1004: This PC is not connected to a network

Shown by: the Remotely app and the Server Manager.

## What it means

No network adapter with a usable IPv4 address was found (no connection, or only a self-assigned 169.254 address).

## What to do

Connect to Wi-Fi or plug in a network cable. If you are connected, check that the router gives out addresses, then try again.
