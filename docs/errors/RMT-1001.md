# RMT-1001: The token is not valid

Shown by: the Remotely app.

## What it means

The text typed as the token is empty, has the wrong length, or contains a character that tokens never contain (0, 1, I, O).

## What to do

A token has 12 letters and numbers, like K7P4-4NX2-QMH9. Type it as the other PC shows it now. Capital letters, dashes and spaces do not matter.
