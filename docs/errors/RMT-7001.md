# RMT-7001: A service action failed

Shown by: the Remotely Server Manager.

## What it means

The administrator helper ran, but Windows or the server program reported an error for the step (start, stop, install, restore).

## What to do

Read manager-helper.log in the server's data folder (C:\ProgramData\Remotely Server). Check that no other program holds the server's files, then try again.

See also: [troubleshooting](../troubleshooting.md), [all error codes](README.md).
