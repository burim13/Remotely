# RMT-5012: The folder was refused as unsafe

Shown by: the Remotely app.

## What it means

The folder contains a path that points outside of it, an absolute path, too many files, expands to more than the allowed size, or arrived as a damaged zip file.

## What to do

Send the files from a new folder you made yourself.
