# RMT-1011: The other PC did not allow the connection

Shown by: the Remotely app.

## What it means

The person at the other PC chose Deny, did not answer in time, or the PC closed the connection before answering.

## What to do

Ask the person to allow the connection when the prompt appears, then try again.
