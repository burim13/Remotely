# RMT-3002: An unencrypted server connection was refused

Shown by: the Remotely app.

## What it means

The server address starts with ws:// (no encryption). Remotely refuses that unless it was allowed on purpose.

## What to do

Use a server address that starts with wss:// and join again with a new invite from the server.
