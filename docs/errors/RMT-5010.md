# RMT-5010: The file is in use by another program

Shown by: the Remotely app.

## What it means

Another program has the file open so Windows does not let Remotely read or replace it, or too many transfers are running at once.

## What to do

Close the other program or wait a moment, then try again.

See also: [troubleshooting](../troubleshooting.md), [all error codes](README.md).
