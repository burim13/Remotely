# RMT-7003: Remotely.Server.exe was not found

Shown by: the Remotely Server Manager.

## What it means

The helper looks for the server program in fixed places and found none.

## What to do

Install the server with the Remotely Server installer, or keep Remotely.Server.exe next to the Manager.

See also: [troubleshooting](../troubleshooting.md), [all error codes](README.md).
