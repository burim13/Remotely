# RMT-5013: The other side cannot do this

Shown by: the Remotely app.

## What it means

The other PC does not share or accept files, or runs an older version that cannot handle this kind of transfer (such as folders).

## What to do

Update Remotely on the other PC and check that file sharing is on there.

See also: [troubleshooting](../troubleshooting.md), [all error codes](README.md).
