# RMT-4003: The server refused the request

Shown by: the Remotely Server Manager.

## What it means

The server answered with an error for this action (for example an unknown device, or a value that is not allowed).

## What to do

Read the message next to the code. If it does not help, export diagnostics and look at the server log.

See also: [troubleshooting](../troubleshooting.md), [all error codes](README.md).
