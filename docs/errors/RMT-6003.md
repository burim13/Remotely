# RMT-6003: Windows refused to change the firewall

Shown by: the Remotely Server Manager.

## What it means

Adding or removing the firewall rule "Remotely Server" failed, usually because the Manager was not allowed to run as administrator.

## What to do

Accept the administrator prompt (UAC) when it appears, or add an inbound TCP rule for the server port yourself in Windows Defender Firewall.
